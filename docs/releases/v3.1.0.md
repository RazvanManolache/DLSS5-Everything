# DLSS5 Everything 3.1

- Components and advanced game settings open in separate windows so you can keep using the library.
- Installer detection uses imported engine modules, SDL renderer choices and exported Godot settings when available. Verified legacy translators and input-loading routes survive reinstalls.
- Reinstalls preserve tuning and respect the selected renderer and enabled state. The recovery journal stops further writes if it cannot record changes safely.
- The update panel verifies published file hashes and explains which Phoenix runtime is installed. Fresh installs default to Lightweight and leave on-screen labels off.

Extract the Windows x64 ZIP and run Dlss5CompatApp.exe. ReShade, Phoenix and models are managed separately through Components. See VALIDATION.json for the validation scope.
