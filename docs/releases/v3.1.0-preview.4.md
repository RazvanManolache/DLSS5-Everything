# DLSS5 Everything v3.1.0-preview.4

**The installer has learned some manners. Mostly.**

- Detects more existing Glide-to-D3D9, DirectDraw-to-D3D9 and D3D8-to-D3D9 wrappers, using matching architecture and exports to select their output API.
- Resolves bounded local legacy renderer modules and explicitly referenced renderer bootstraps. No game-name routing table is added.
- Adds a process-local DirectDraw COM compatibility proxy and narrowly scoped per-user DirectPlay registration support for eligible legacy translation routes. Original files are backed up through the normal installation journal.
- Records deliberately retired obsolete components so installation verification does not mistake their intentional absence for a broken install.
- Adds `--launch-plan`, explicit `--api`/`--proxy` installer choices, and a validated local Remix renderer target. Existing renderer bridges receive a warning instead of being overwritten blindly.
- Preserves valid optional runtime selections and tolerates Phoenix 0.18 license notices during component import.
- Tightens Phoenix capability detection and forwards supported control operations without requiring legacy native-game exports from standalone-only addons.

Use **Components** to download the current published Phoenix build. This release checks the public **Phoenix 0.18** packages through the component importer; the Everything download does not bundle Phoenix, NVIDIA model DLLs or weights. Importing a compatible local development build remains an explicit choice.

The Windows archive includes the self-contained app, its first-party workers, software-renderer hook, x86/x64 legacy compatibility proxies and the existing model-free media-player runtime, with distribution notices. Android companion sources/APKs, local game settings, captures and historical feeder-preservation archives are excluded. Generated media-player binaries remain outside the source archive.

## Validation boundaries

Release gates cover managed installer/scanner/control contracts, architecture-specific legacy COM CPU contracts and export forwarding, self-contained packaging and license inventories. The component acceptance check uses public Phoenix 0.18 downloads rather than recompiling Phoenix source. Exact results and hashes are included in `VALIDATION.json`.

This is still a preview. These release checks do not certify every retail game, provide a new full graphics matrix or establish AMD/Intel/VR hardware performance. Previous gameplay and performance evidence retains its original build identities.
