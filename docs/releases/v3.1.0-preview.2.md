# DLSS5 Everything 3.1.0-preview.2

More knobs. Fewer installer staring contests.

- Current Phoenix appearance, intensity, style, color and processing-chain controls,
  with matching bounds and availability rules.
- Bounded installation checks avoid a Windows process-inspection stall.
- Screen Studio keeps the initial frame from static windows and handles capture-size
  changes independently of the preview size.
- Configured model and runtime locations are checked during installation and preflight.
- Standard Phoenix packages take precedence over experimental compatibility packages.
- Driver-profile tools, mod-coexistence planning, recovery and optional-model integration.
- Optional Phoenix Video Player integration uses the shared model library and processing
  recipes. Player/runtime components retain their own source and dependency notices.

## Downloads

Extract the Windows x64 ZIP into a writable folder and run `Dlss5CompatApp.exe`.
.NET is included; native helpers require the
[Microsoft Visual C++ x64 runtime](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist).
Use Components for compatible Phoenix and ReShade packages. Phoenix is released
separately; this release does not bundle the Phoenix addon or an NVIDIA model DLL.
The Android companion remains a separate project.

No extracted model weights, personal configuration, test captures or Android APK
are included. The source ZIP contains the tracked Everything source snapshot;
external projects remain separate dependencies or submodules.

## Validation at publication

- 1,221 application tests passed; 9 conditional live/device tests were skipped in
  that run. Separate synthetic Screen Studio checks passed 8/8.
- Live graphics/control checks passed 5/5; installed live-control routes passed 6/6.
- Existing-install checks passed 82/82, then the generated game fixtures were
  reset and rebuilt. Fresh-install checks passed 82/82.
- DOS native, NVIDIA and Phoenix checks passed for both installation phases.
- The exhaustive 656-entry game/transport/model matrix is **still running**.
  Completed counts and exact identities at publication are attached in `VALIDATION.json`.

These are development-source results using a separately built Phoenix candidate,
not qualification of every publicly released Phoenix combination. The release
build changes version metadata; its package inspection and source identities are
recorded separately. Fixture worker timings are not gameplay FPS or isolated GPU
benchmarks. No new physical-phone, camera, headset, retail-game or discrete
AMD/Intel hardware qualification is claimed.
