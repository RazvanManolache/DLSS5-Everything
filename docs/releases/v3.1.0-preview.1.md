# DLSS5 Everything 3.1.0-preview.1

The installer has learned a few more ways to keep old games out of trouble.

- Correct x64 DirectDraw wrappers and architecture-aware legacy installation.
- Opt-in software-device ReShade support, guided repair and Phoenix hardware-helper routing.
- Official public-release fallback when GitHub's API rate limit interrupts component setup;
  downloaded assets still require their SHA-256 checks.
- Retire an obsolete feeder configuration together with its verified old feeder,
  preserving unrelated settings and restoring original bytes on uninstall.
- Reject incorrectly typed vendor DLL candidates without crashing component discovery.
- On-demand DOS graphics setup uses DOSBox Enhanced's pinned, signature-checking
  recipe, retains vendor notices and cleans partial staging on failure or cancellation.

## Downloads

Extract the Windows x64 ZIP into a writable folder and run `Dlss5CompatApp.exe`.
.NET is included. Native helpers require the
[Microsoft Visual C++ x64 runtime](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist).
Use Components to obtain compatible Phoenix and ReShade packages and supply a model separately.
The Android companion remains a separate project.

No NVIDIA model DLL, extracted weights, personal configuration or Android APK is included.
