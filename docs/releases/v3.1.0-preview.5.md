# DLSS5 Everything v3.1.0-preview.5

- Uses the latest published Phoenix release (0.19 at validation), with freshness checks and a visible update notice.
- Updates the DOSBox Enhanced source dependency to 0.6.2 and the bundled model-free Video Player to 0.1.0.
- Falls back to local game artwork or executable icons when a cover is unavailable.
- Downloads the required runtimes and both model families from the library button, with progress in place.
- Backs up and retires verified obsolete addon files; unknown conflicts remain visible before installation.
- Corrects automatic DLSS input-mode routing and preserves explicit configuration choices.
- Detects verified renamed DirectDraw translators and migrates them through the normal backup journal, using architecture/import/export evidence rather than game-name rules.

The application, native helpers, source archive, dependency pins and package inventories are updated together. Phoenix/ReShade and models remain separately managed downloads; no NVIDIA model DLLs, extracted weights, personal settings or Android APK/source are bundled.

Validation covers targeted application tests, hosted Windows CI, release-package inspection and component-version/hash checks. It does not repeat the full game/API matrix or qualify physical phone, webcam, VR or discrete AMD/Intel behavior. Existing reports retain their own version and hardware scope.
