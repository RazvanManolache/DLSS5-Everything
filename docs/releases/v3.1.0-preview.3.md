# DLSS5 Everything 3.1.0-preview.3

Controls should queue politely. They have now been taught manners.

This preview includes the features and installer/capture fixes from
[preview.2](v3.1.0-preview.2.md), plus a control-client concurrency fix:

- Requests waiting for the same game wait asynchronously inside Everything.
  They no longer occupy the worker threads needed by other application work.
- The Windows mutex still serializes commands across different processes.
- Cancellation and the original deadline include time spent waiting in the queue.
- Idle game queues are released rather than retained for the application's lifetime.
- CI now explicitly checks control behavior with a two-CPU configuration.

The previous parallel-control failure reproduced locally in that configuration.
After the fix, all 84 control tests and 1,223 application tests passed, with 9
conditional device/live checks skipped. Hosted CI and package identities are
recorded with the release assets.

The exhaustive graphics matrix continues against its frozen development
application/Phoenix candidate. Its evidence remains attached to that exact
snapshot; the new control-client checks are recorded separately. See
`VALIDATION.json` for completed and pending coverage. No fresh retail-game,
physical-phone, camera, headset or older-GPU qualification is implied.

## Downloads

Extract the Windows x64 ZIP into a writable folder and run `Dlss5CompatApp.exe`.
.NET is included; native helpers need the
[Microsoft Visual C++ x64 runtime](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist).
Phoenix and ReShade are separately managed components. Model DLLs, extracted
weights, personal configuration and the Android companion are not bundled.

The separate [Phoenix Video Player source repository](https://github.com/RazvanManolache/dlss5-phoenix-video-player)
now contains its build guide, tests and retained upstream credits. That source
publication is separate from the model-free companion already bundled here.
